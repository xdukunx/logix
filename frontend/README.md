# Logix Dashboard (React)

Admin dashboard for the Logix central server, built with React 19 +
TypeScript + Vite on Meta's [Astryx](https://github.com/facebook/astryx)
design system. This is a port of the legacy vanilla-JS dashboard in
`../server/static/` (kept as a no-Node fallback).

## Development

```bash
npm install
npm run dev        # http://localhost:5173, proxies /api to localhost:8791
```

Start the backend first (from `../server/`):

```powershell
$env:LOGIX_DEV_MODE='1'; $env:ADMIN_EMAILS='admin@example.org'
py -m uvicorn main:app --host 127.0.0.1 --port 8791
```

Login is email + password (`ADMIN_EMAILS` + `LOGIX_ADMIN_PASSWORD`). With
`LOGIX_DEV_MODE=1` the admin password defaults to `admin123`, so you can sign
in as `admin@example.org` / `admin123` straight away.

## Production

```bash
npm run build      # outputs dist/
```

`server/main.py` automatically serves `frontend/dist/` at `/` when it exists
(no server config needed). Rebuild after UI changes; the server picks the
directory at startup.

## Structure

- `src/api.ts` — token storage + authenticated fetch (401 → login screen)
- `src/App.tsx` — auth gate, hash-routed tabs, TopNav/SideNav shell
- `src/views/` — Monitoring, Analytics, Devices, Settings
- `src/chrome/` — Login, AlertsBell, ReportDialog
- `.claude/CLAUDE.md` — Astryx agent conventions (generated by `npx astryx init`)

UI work should follow `.claude/CLAUDE.md`: discover components with
`npx astryx build "<idea>"` / `npx astryx component <Name>`, use design
tokens (`var(--color-*)`) instead of raw hex/px, and prefer Astryx layout
components (Stack/Grid/Card) over raw `<div>`s.
