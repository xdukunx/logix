>_ LOGIX · Windows Client
Never surveillance, never shaming.

The complete string reference.

Every user-facing string in the LogiX client, Bahasa Indonesia primary with English alongside for a future en locale. Grouped by surface. Tone: respectful, plain, second-person Anda — never surveillance, never shaming.

Tone rules
▸Plain Indonesian, no jargon. Say "kode", not "token".
▸Second person Anda; the lab, not "the system", acts.
▸"Pemberitahuan" by default; "Peringatan" only when truly urgent.
▸Explain the why, never accuse or imply wrongdoing.
▸Short enough for a 260px widget; front-load the verb.
▸Privacy stated plainly & often — a promise, not fine print.

⚑

Flagged strings — risk of sounding accusatory

Copy that could read as surveillance, blame, or a threat — with a kinder alternative already adopted above.

✕ RISKY
"Aktivitas Anda sedang dipantau."
Sounds like live over-the-shoulder watching.
✓ KINDER
"Sesi ini dicatat untuk kehadiran & penggunaan lab."
States purpose, not observation.
✕ RISKY
"Admin mengambil alih layar Anda." / "Screen captured."
"Mengambil alih" implies seizure/control.
✓ KINDER
"Admin baru saja mengambil satu tangkapan layar."
One snapshot, with notice — the adopted string.
✕ RISKY
"Sesi Anda dihentikan paksa." / "You were locked out."
"Paksa" / "locked out" sound punitive.
✓ KINDER
"Sesi Anda dijeda, bukan diakhiri."
Pause framing, work preserved.
✕ RISKY
"Kode tidak valid!" (with alarm styling)
Exclamation + red feels like a reprimand for a typo.
✓ KINDER
"Kode salah. Periksa kembali 12 karakter."
Calm, tells them how to fix it.
✕ RISKY
"Peringatan: Anda belum mengisi data." (on every field)
"Peringatan" over-escalates a normal empty form.
✓ KINDER
"Lengkapi Nama, NIM/ID, tipe akses, tujuan, dan keterangan."
A gentle to-do, reserves "Peringatan" for true urgency.
