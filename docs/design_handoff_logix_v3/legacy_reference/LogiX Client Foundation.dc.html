The fullscreen popup and corner widget a researcher meets at the keyboard. Deep-navy, data-forward, Indonesian-first — every surface built from WPF primitives (Border, StackPanel, Path, TextBlock). No emoji, no decoration for its own sake. Signal over noise.

01
Brand direction

Blue is the direction. Everything else is a theme.

The client speaks the dashboard's language — accent #2563EB on a deep-navy surface. That is Option A, and it is the default. Because color is config-driven (branding.colors.*), a specific lab or faculty can re-theme without a rebuild — that is all Option B is now.

OPTION B Kustomisasi branding per-lab branding.colors.*

Not an alternative to choose — a capability. A faculty that needs its own identity swaps the accent in config; the layout, type, and structure never change. Same instrument, different livery.

03
Type · data as hero

The number is the interface

Every client surface has one thing that matters most — elapsed time, a countdown, an invite code. It gets set in oversized tabular Consolas and given room. Everything else is Segoe UI, quiet, in support. This is the anti-slop move: hierarchy by scale, not by adding chrome.

Fallback-safe: drawn as if only Segoe UI & Consolas exist. No web font ever loads on a lab machine — Poppins/Montserrat are treated as absent.

04
Components · WPF-safe

Built from Border, StackPanel & Path

Line icons are vector Path geometry — never emoji. Controls sit on hairline borders with a small radius, so the surface reads engineered rather than bubbly.

Personality

The user is a researcher, not a suspect.

Respectful, calm, Indonesian-first — "Selamat datang", "Mulai Sesi", "Mohon simpan pekerjaan". No alarms unless something is truly urgent. Privacy is stated plainly and often. The client should feel like a well-made instrument at the door — precise, quiet, trustworthy — not a guard watching over your shoulder.
