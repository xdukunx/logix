An always‑on‑top timer, in three states.

Fixed width (260px), variable height. A non-rectangular shape drawn with a vector Path — a clipped tab notch top-right — on a #0B1017 surface with a hairline accent stroke, draggable. The clock is the hero; everything else is quiet. Height animates between states; the Path + Clip regenerate per height so the outline never tears.
